# LearnTrack - Student & Course Management System

##  Project Description

LearnTrack is a console-based Java application used to manage Students, Courses, and Enrollments.

This project is built using Core Java concepts and follows a layered architecture:

* Entity
* Repository
* Service
* Main 

---

##  Features

###  Student Management

* Add Student
* View Students
* Deactivate Student

###  Course Management

* Add Course
* View Courses

###  Enrollment Management

* Enroll Student into Course
* View Enrollments

---

##  Technologies Used

* Core Java
* ArrayList (in-memory storage)
* IntelliJ IDEA

---

##  Concepts Covered

* OOP (Encapsulation, Classes, Objects)
* Collections (ArrayList)
* Layered Architecture (Entity, Repository, Service)
* Control Flow (if/else, switch, loops)

---

##  How to Run the Project

1. Open project in IntelliJ IDEA
2. Navigate to:
   `com.airtribe.learntrack.Main`
3. Run the `Main.java` file
4. Use the menu options in console
